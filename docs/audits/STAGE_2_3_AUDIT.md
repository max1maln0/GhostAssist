# Stage 2.3 — технический аудит

База: `d5be0b0` (`origin/main`). Рабочая директория до аудита была чистой.
Windows-среда, Python 3.10.22, 3.11.18 и 3.12.10: исходные 57 тестов проходят на каждой версии; Ruff проходит на 3.12. Автоматические тесты не подтверждают физические нажатия клавиш, работу драйверов и многоэкранной конфигурации.

## Карта компонентов и границы проверки

| Компонент | Назначение и зависимости | Риски и пробелы проверки |
| --- | --- | --- |
| Dashboard и трей | Tk/CustomTkinter, pystray; управляет дочерним процессом и настройками | Отказы ввода-вывода, асинхронное обновление виджетов, ручная проверка трея |
| Служба и IPC | Очередь команд Tk, stdin дочернего процесса, Windows named mutex/event | Аварийный выход, потеря канала, права доступа к именованным объектам |
| Горячие клавиши | pynput, валидатор, запись в .env и перезапуск службы | Асинхронная регистрация, конфликты с другими приложениями и раскладки; физическая клавиатура |
| Настройки и профили | Pydantic, dotenv, атомарная замена .env, Markdown | Ошибки записи и некорректная кодировка, безопасность путей |
